# Prompt — Swissperiences Post-Trip Report Generator

Cole este prompt no Claude.ai (projeto Swissperiences) depois de cada experiência com um convidado:

---

Cria um **Post-Trip Report** no estilo editorial Swissperiences para o(a) [NOME DO CONVIDADO].

## Dados da viagem:
- **Convidado(a):** [nome, de onde veio, personalidade em poucas palavras]
- **Datas:** [ex: 17–20 fevereiro 2026]
- **Roteiro dia a dia:**
  - Jour 01: [cidade → cidade, o que fizeram, momentos marcantes]
  - Jour 02: [idem]
  - Jour 03: [idem]
  - Jour 04: [idem]
- **Pessoas envolvidas:** [quem mais participou, apelidos, momentos engraçados]
- **Momentos destaque:** [cenas memoráveis, piadas internas, acidentes épicos]
- **Fotos disponíveis:** [descreve brevemente as fotos que tens — ex: "selfie no carro", "sunset em Montreux", "ski em Bretaye"]

## Formato do output:

Cria o conteúdo completo para um PDF de 12-16 páginas, com esta estrutura:

### Página 1 — Capa
- Título grande: "[Nome]'s [Adjetivo] Experience."
- Local · Região · Mês Ano
- Subtítulo poético em português (2–3 linhas, tom íntimo e real)
- Rodapé: "A Pause — Designed · Internal Document"

### Páginas 2–11 — Diário da viagem
Para cada dia/momento, criar:
- **Label:** JOUR XX · [SUBTÍTULO EM FRANCÊS MAIÚSCULO]
- **Título:** Frase curta e impactante (mix de francês/português/inglês)
- **Subtítulo:** Rota (ex: "Villars → Vevey · Jeudi")
- **Texto narrativo:** 3–5 linhas em português brasileiro informal. Tom: entre amigos, com humor, referências internas, mas com uma camada poética por baixo. Nunca influencer. Nunca forçado.
- **Legendas das fotos:** Curtas, estilo editorial — 3 fragmentos separados por " · " (ex: "Action mode · Sol & neve · Rock baby, rock hard")
- **Uma página full-bleed** para o momento mais cinematográfico (ex: sunset, montanha épica)

### Páginas 12–13 — Trip Awards
Estilo premiação irônica e carinhosa. Categorias personalizadas baseadas nos momentos reais da viagem. Para cada award:
- **Categoria** (em inglês, caps, tom editorial — ex: "BEST CONTEMPLATIVE BACK")
- **Vencedor(a)**
- **Descrição** (1 linha, espirituosa)
- Rodapé: "No [referência interna] foram prejudicados na criação destes awards."

### Página final — Fechamento
- Foto silhueta ou contemplativa (full-bleed)
- "A pause — designed."
- "Switzerland is not a destination. It's a state of mind."
- "Você conhece alguém que merece uma pausa assim?"
- swissperiences.ch · @swissperiences
- "Curated experiences in the Swiss Alps · By invitation only"

## Regras de tom:
- Português brasileiro informal (como falar com amigo próximo)
- Títulos de seção em francês (dá elegância editorial)
- Legendas podem misturar PT/EN/FR
- Humor real, nunca genérico — piadas internas > trocadilhos
- Poesia sutil, nunca explícita — "o ar suíço nocauteou o rockeiro londrino" > "que experiência incrível"
- Nunca usar: "incrível", "maravilhoso", "amazing", "unforgettable", "once in a lifetime"
- A vibe é: revista independente encontra carta pessoal encontra brand book
- Cada página deve funcionar como um Instagram carousel solo

## Output:
Me entrega o conteúdo completo, página por página, com:
1. Texto de cada seção
2. Indicação de onde cada foto entra (referenciando as fotos que descrevi)
3. Sugestões de layout (full-bleed, grid 2x1, etc.)
4. Trip Awards completos

Se tiver dúvidas sobre algum momento ou quiser sugerir categorias de awards, me pergunta antes de finalizar.
